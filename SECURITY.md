# Security policy

Retramo runs inside your editor and reads your repository, so security reports matter to us.

## Reporting a vulnerability

Please email **hello@zoomieslabs.dev** with:

- what you found and where (file and line, or the steps to reproduce it)
- what an attacker could do with it
- the Retramo and VS Code versions you tested

Don't open a public issue for a vulnerability. We'll reply within a few days and keep you posted until it's fixed.

## Scope

Anything in this repository: the VS Code extension and the telemetry server in `server/telemetry/`. The extension's security model is described in the README, under [Security](README.md#security).
